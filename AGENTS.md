# Contributor guidance

## Choose the language for the task

This project is not restricted to JavaScript or TypeScript. Choose the
programming language that best fits the task. The existing TypeScript API is
not a reason to use TypeScript for every future component.

Consider the problem, suitable libraries, runtime and deployment needs and
long-term maintenance. When adding a language, document how to set it up and
run its checks. Update CI and deployment instructions so the new component can
be built, tested and shipped reliably.
